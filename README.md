# RMUTI Blog

## Overview
RMUTI Blog is a mini-project for the Database Management course. This web blog allows users to create, read, update, and delete blog posts while interacting with a structured database.

## Features
### Super Admin
- Assign other users as admins
- Edit and delete user information
- Restrict users from posting or commenting
- Delete user posts

### Admin
- Edit and delete user information
- Restrict users from posting or commenting
- Delete user posts

### User
- Create, edit, and delete posts
- Comment on their own or others' posts

## Technologies Used
- Frontend: HTML, CSS, JavaScript
- Backend: PHP
- Database: MySQL
- Styling: CSS 

## Installation
1. Clone the repository:
   ```sh
   git clone https://github.com/KannJedsada/rmutiblog.git
   ```
2. Navigate to the project directory:
   ```sh
   cd rmutiblog
   ```
3. Set up the database:
   - Import `database.sql` into MySQL
   - Configure `config.php` with database credentials

4. Start a local server (e.g., XAMPP, MAMP, or built-in PHP server):
   ```sh
   php -S localhost:8000
   ```
5. Open the blog in your browser:
   ```sh
   http://localhost:8000
   ```
